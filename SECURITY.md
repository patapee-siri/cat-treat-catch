# Security Policy

Our Cats is a static, client-side game: no accounts, no server, no network calls beyond
loading its own files. The only data it stores is your scores and settings in your browser's
`localStorage`.

## Supported versions

Only the latest version on the `main` branch (the one deployed to GitHub Pages) is supported.

## Reporting a vulnerability

Please report privately rather than opening a public issue:

1. Go to the repository's **Security** tab and choose **Report a vulnerability**
   (GitHub private vulnerability reporting), or
2. Contact the maintainer through GitHub: [@patapee-siri](https://github.com/patapee-siri).

Include what you found, how to reproduce it, and the browser/device you used. This is a hobby
project, so there is no bounty, but reports are appreciated and I'll aim to respond within a
couple of weeks and credit you if you'd like.
